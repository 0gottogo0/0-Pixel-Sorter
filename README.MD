## Building 

Requirements:

```
Raylib > 6.0
CMake > 3.16
```

To builb you can use the included bash scripts or:

```bash
# Not needed if this is your first time building
rm -rf build

# Make b build
cd builuild folder
mkdir -pd

# Run cmake
cmake ..
cmake --build .
```

To run just run the program in the build folder
